# Classification par âge

Réponses attendues aux questionnaires (Apple et IARC / Google Play) :

| Thème | Réponse |
|---|---|
| Violence (réaliste, cartoon, fantastique) | Aucune |
| Peur / horreur | Aucune |
| Langage grossier | Aucun |
| Contenu sexuel, nudité | Aucun |
| Drogues, alcool, tabac | Aucun |
| Jeux d'argent (réels ou simulés) | **Aucun** : pas de loot box ; les pièces se gagnent en jouant et servent seulement à débloquer des apparences à prix fixe |
| Achats intégrés | Aucun |
| Interaction entre utilisateurs, chat, contenu généré | Aucun |
| Partage de localisation | Non |
| Accès Internet illimité / navigateur | Non |

Classification attendue : **4+** (Apple), **PEGI 3 / Tout public** (IARC).

Les passagers qui « s'impatientent » ont une expression fâchée cartoon et s'en vont à pied : aucune violence.
